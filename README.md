## Game Overview
 Genre: Platformer/Shooter
 Platform: Windows
 Development Time: 5 weeks
 Unity/Unreal Version: 6.2
 Course: GAME 360 - Development with Game Engines, Fall 2025

 

## How to Play
WASD to move
Click or press F to Fire
Space to jump
Double Space to double jump
Left Shift to Dash

## Features

- Shooting
- Platforming
-Narrative Text Navigation
⦁	Dashing
⦁	Double Jump
- Score System
- Collectibles
- Enemy AI
- Multiple Levels/Scenes
- Win/Lose Conditions

## Development Statistics
- Total Commits: 82

## Post-Mortem

What I learned the most was how to code. I came into this not knowing anything about coding. Afterwards, I feel confident that I can make small bits of code that get what I want done. I also have developed a relative familiarity with Unity and know how to navigate the inspector and add and edit components such as colliders and rigidbodies.
